# MERVE Café — Luxury Café & Restaurant

Премиальный сайт кафе/ресторана на **Flask + SQLAlchemy + Flask-Login**, с JWT-API, тёмно-золотым дизайном (GSAP / Lenis / Swiper / Three.js-эффекты), онлайн-заказами, бронированием столов, программой лояльности и полноценной админ-панелью.

> **Город:** Душанбе · **Валюта:** сомони (сом.) · **Язык интерфейса:** русский

---

## ✦ Возможности

**Витрина (для гостей)**
- Кинематографичная hero-секция с анимированной подачей и частицами
- Меню с живым поиском, фильтром по категориям и сортировкой (через JSON-API), карточки с 3D-наклоном
- Бронирование стола + VIP-зона, статус брони обновляется в реальном времени
- Онлайн-заказы: корзина, изменение количества, оформление (доставка/самовывоз), отслеживание статуса
- Программа лояльности: 5 кофе → 1 бесплатно, баллы, уровни Bronze / Gold / Platinum
- Личный кабинет: профиль, аватар, брони, заказы, избранное, уведомления
- Галерея с фильтрами и лайтбоксом, страницы «О нас», «Контакты» (карта + форма), журнал/блог

**Админ-панель (`/admin`)**
- Дашборд: выручка за 7 дней, популярные блюда, загруженные часы, ключевые метрики
- Управление бронями (подтвердить/отклонить), заказами (смена статуса)
- CRUD меню и категорий, акции/промокоды, клиенты + VIP-статусы
- Редактор контента главной, галерея, блог, входящие сообщения

**API (JWT)** — `/api/auth/token`, `/api/menu`, `/api/me`, `POST /api/bookings`

## ✦ Технологии

Flask 3 · Flask-SQLAlchemy · Flask-Login · PyJWT · SQLite (по умолчанию) или PostgreSQL · GSAP · Lenis · Swiper · ванильный JS. Изображения — самодостаточные SVG-плейсхолдеры (работают офлайн).

## ✦ Быстрый старт

Требуется **Python 3.10+**.

```bash
# 1. Перейдите в папку проекта
cd merve-cafe

# 2. Создайте и активируйте виртуальное окружение
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate

# 3. Установите зависимости
pip install -r requirements.txt

# 4. (необязательно) настройте окружение
cp .env.example .env              # затем при желании отредактируйте .env

# 5. Заполните базу демо-данными (создаёт таблицы + админа + меню)
python seed.py

# 6. Запустите сайт
python run.py
```

Откройте **http://127.0.0.1:5000**

## ✦ Доступ в админку

После `python seed.py` автоматически создаётся администратор:

| Логин   | Пароль      |
|---------|-------------|
| `admin` | `merve2026` |

Админ-панель: **http://127.0.0.1:5000/admin**

Также создаётся тестовый гость: `guest` / `guest123`.

> Смените пароль администратора перед публикацией в продакшн.

## ✦ База данных

По умолчанию используется **SQLite** — файл `instance/merve.db` создаётся автоматически, ничего настраивать не нужно.

Для **PostgreSQL** укажите в `.env`:

```
DATABASE_URL=postgresql://user:password@localhost:5432/merve
```

Затем выполните `python seed.py` ещё раз. Префикс `postgres://` нормализуется автоматически.

## ✦ Запуск в продакшн

```bash
# через gunicorn (входит в requirements.txt)
gunicorn "run:app" --bind 0.0.0.0:8000
```

В продакшне задайте `FLASK_CONFIG=production`, надёжные `SECRET_KEY` и `JWT_SECRET_KEY`, а также `DATABASE_URL` для PostgreSQL в `.env`.

## ✦ Заметки

- Фотографии меню/галереи — векторные SVG-плейсхолдеры. Загрузите свои изображения через админку (поля «Фото») — они сохранятся в `app/static/uploads/`.
- Контактные данные (адрес пр. Рудаки 88, телефон) и соцсети — демо. Поменяйте их в `app/templates/partials/footer.html`, `contact.html` и через раздел «Контент» в админке.
- Карта на странице контактов — встраиваемый OpenStreetMap, ключи API не требуются.
