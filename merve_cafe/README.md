# ☕ Кафе МЕРВЕ — Веб-сайт

Современный люксовый сайт для кафе МЕРВЕ в Душанбе.
3D-анимации, кинематографическая сцена, аутентификация, SQLite.

## 🚀 Запуск

```bash
# 1. Установите зависимости
pip install flask

# 2. Запустите сервер
python app.py

# 3. Откройте браузер
http://localhost:5000
```

## 📁 Структура

```
merve_cafe/
├── app.py              — Flask приложение
├── cafe.db             — SQLite база данных (создаётся автоматически)
├── requirements.txt
├── static/
│   ├── css/style.css   — Полный CSS
│   └── js/
│       ├── main.js         — GSAP анимации, курсор, scroll
│       └── three-scene.js  — Three.js 3D сцена героя
└── templates/
    ├── base.html       — Базовый шаблон (навигация, футер)
    ├── index.html      — Главная страница
    ├── menu.html       — Меню
    ├── about.html      — О нас
    ├── booking.html    — Бронирование (требует авторизации)
    ├── reviews.html    — Отзывы
    ├── contact.html    — Контакты
    ├── login.html      — Вход
    └── register.html   — Регистрация
```

## ✨ Особенности

- **3D сцена** — Three.js: золотой торус-кнот, частицы, пар, кольца
- **Параллакс мышью** — Кинематографическое движение камеры
- **GSAP анимации** — ScrollTrigger, stagger reveals, счётчики
- **3D tilt карточки** — Эффект наклона при наведении мыши
- **Пользовательский курсор** — Золотой магнетический курсор
- **SQLite база данных** — Пользователи, бронирования, отзывы, меню
- **Авторизация** — Login / Register с SHA256 хешированием паролей
- **Полностью адаптивный** — Mobile-first дизайн
- **Тёмная палитра** — Premium dark coffee aesthetic
